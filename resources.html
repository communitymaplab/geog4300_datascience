Data Science in Geography: resource page

There are multiple free resources online to help grow your ability to learn R for geographic analysis. Here’s a few.

Learning R

  • Hands-On Programming with R: This online book by Garrett Grolemund starts from the very basics and is a good primer on how to get started in R and understand things like the difference between a vector and a list or what c(3, 5) means.

  • R for the Rest of Us Only the introductory video lessons at this website are free, but you may find it useful as a place to start.

  • Learning Statistics with R Good overview of getting started in R and doing statistical analysis, with an emphasis on psychology.

  • Introduction to Statistics: an integrated textbook and workbook using R. Well organized and recent textbook walking through R for statistical work.

  • R for Psychological Science Very nice online book introducing R for analysis. It’s still incomplete for more advanced methods, but good for getting started.

  • Exploratory Data Analysis with R (Peng) Book focused specifically on exploratory analysis with tidyverse tools by Roger Peng, who also had a podcast about data analysis for several years.

  • Exploratory Data Analysis in R (Gimond) A more recent web based book on using R for EDA.

  • Teacup Giraffes and Statistics: Whimsically themed website with lots of interactive exercises to get you started in R, both loading data and doing statistical analysis.

  • Swirl: An R package that is designed to teach you R while using R.

  • Tidyverse Workflow: From its creators. It walks through the different packages/functions within the tidyverse.

R for research

  • The Big Book of R: It’s a book of books! This text gives you links to a bunch of online resources for using R in a variety of academic and computational contexts.

  • R for Data Science: The main text by the authors of the tidyverse on how to use R for exploratory data analysis, data wrangling, and visualization. It assumes you know your basic way around R.

  • Advanced R: Hadley Wickham (the main author of the tidyverse) wrote this book to cover more advanced programming tasks in R.

  • Geocomputation with R: Online, open source book by Lovelace et al. that provides detailed examples of how R can be used for geospatial analysis.

  • Rspatial.org: Another site providing both an overview of spatial functions in R and examples of applications. It has the most detail on analysis of raster data. Created by Robert Hijmans, who helped author the terra and raster packages.

  • Spatial Data Science: This book by Pebesma and Bivand, hosted on the Rspatial site, is another more technical guide to doing spatial analysis using R. Pebesma is the main author for the sf package.

  • Introduction to Econometrics with R: This book provides a somewhat technical but useful walkthrough of everything from basic descriptive analysis through time series models and measuring causal effects.

  • Tidy Modeling with R: Max Kuhn and Julia Silghe walk through the tidymodels package, which provides tools for machine learning and other AI assisted modeling.

Connecting R with other tools and data

  • ESRI’s R-ArcGIS Bridge: This tool allows you to access, analyze, and edit feature datasets hosted on ArcGIS Online. It also allows you to use ArcGIS functions in R or to bring R functions into the ArcGIS toolbox.

  • qgisprocess: This package allows you to access the functions in the QGIS Processing Toolbox for data stored in R. Several functions in QGIS are more efficient than the equivalent version in sf, so this can be useful.

  • reticulate: Developed by Posit, the reticulate package allows you to create a virtual Python environment in R and transfer objects such as data frames between R and Python. This is useful if Python offers tools that are better suited to your analysis. The Positron application created by Posit offers a true Python environment, but lacks the ability to move objects back and forth. You instead save data in one environment and then load it in another.

Data visualization

  • R Graphics Cookbook: This book by Winston Chang walks through a variety of examples of how to specify plots using ggplot.

  • Data Visualization: A Practical Introduction: Kieran Healy has lots of great material out there both on the practicals of data science but also the social science behind it. This is his book walking through data visualization in R.

YouTube R/stats people

  • Julia Silge: Julia works for Posit and has been providing materials on how to use R effectively for awhile. There’s a lot here on doing modeling and machine learning in R.

  • Equitable Equations on YouTube: This account has some helpful looking videos with slow and thorough walkthroughs of working in R with the tidyverse. This link goes to his “All about R” playlist.

  • R Programming 101: Quick videos on getting started in R and doing statistical analysis. Plus he’s British!

  • StatQuest with Josh Starmer: A platform neutral page that focuses more on the concepts of various statistical approaches. Good graphics!

Social media/communities

  • R-Bloggers: Feed of R related articles that may be of interest.

  • RLadies: What it sounds like. Online community of (primarily) women with local chapters around the world.

  • TidyTuesday: Cross platform community that has a new data challenge every week.
