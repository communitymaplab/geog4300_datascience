Data Science in Geography: Data files

Below is a table showing the main datasets in the course. All of them are available on Github, but you should also be able to right-click the link to download them locally.

It’s HIGHLY recommended that you save these to a single folder for all your course materials in a folder called “data.” Most course scripts reference the Github repository to load these datasets, but this makes them easy to find should you not have access to that repo.
